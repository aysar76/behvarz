# تغییرات (Changelog)

## فاز ۵ — تعاملات حرفه‌ای و سرمایه روایت (پایه)

- **دنبال‌کردن** موضوع/مسئله/تجربه/عضو (`Follow` پلی‌مورفیک) با اعتبارسنجی هدف سمت سرور؛ دنبال‌کردن عضو با پروفایل خصوصی و دنبال‌کردن خود ممنوع.
- **ذخیره محتوا** (خواندنی‌های من) برای مسائل/تجربه‌ها (`SavedItem`) + صفحه `/saved`.
- **«تشکر حرفه‌ای»** به‌جای لایک عمومی روی پاسخ و تجربه (`ProfessionalThanks`) + شمارنده تراکنشی `thanksCount`؛ تشکر به محتوای خود ممنوع.
- **پروفایل سرمایه حرفه‌ای** (`/users/[id]`): تجربه‌های منتشرشده، مسائل حل‌شده، ارجاع‌های معتبر، اجرای موفق توسط دیگران، تشکر دریافتی + **نشان‌های مبتنی بر شواهد** (بدون لایک/لیدربورد).
- **خوراک حرفه‌ای** (`/feed`): بر اساس موضوع‌ها/اعضای دنبال‌شده (مرتبط موضوعی، نه محبوبیت).
- حالت تعامل (ذخیره/دنبال/تشکر) در Serializer ها از طریق `getInteractionState`؛ دکمه‌های تعاملی در صفحات مسئله/تجربه و پاسخ.
- مجوزهای RBAC جدید `interactions:follow/save/thanks` و `profile:read:other`؛ Audit Log برای همه تعاملات.
- Migration فاز ۵ (`Follow`، `SavedItem`، `ProfessionalThanks` + `thanksCount`).
- صفحه ناوبری جدید «خوراک حرفه‌ای».

## فاز ۴ — بانک تجربه‌های میدانی

- مدل تجربه ساختاریافته: عنوان، مسئله/موقعیت، شرایط، اقدام، منابع، چالش‌ها، نتیجه، درس‌آموخته‌ها، پیشنهاد برای دیگران، برچسب‌ها + اسلاگ قابل اشتراک (`/experiences/[slug]`).
- ثبت پیش‌نویس/پیش‌نمایش/انتشار/ویرایش؛ وضعیت‌ها (user_generated → under_review → reviewed → featured → archived) با انتقال معتبر و تفکیک «تجربه شخصی» از «محتوای بررسی‌شده/برگزیده».
- **تبدیل پاسخ موفق اتاق به تجربه** (`POST /api/problems/[id]/convert-to-experience`) — چرخه بسته دانش (مسئله ← راهکار ← تجربه).
- **ارجاع تجربه در پاسخ‌ها** (`experienceSlugs`) — تعداد ارجاع بخشی از سرمایه روایت.
- **«این تجربه را اجرا کردم» + ثبت نتیجه اجرای مجدد** (`ExperienceReuse` با upsert) — سرمایه روایت مبتنی بر اثر، نه لایک.
- هشدار/کنترل محتوای حساس + صف ناظر برای تجربه‌ها؛ گزارش تجربه (`ContentReport.experienceId`) + نظارت مخفی/حذف/بازیابی.
- صفحه‌های `/experiences`، `/experiences/new`، `/experiences/[slug]` و فعال‌سازی آیتم «بانک تجربه» در ناوبری؛ بخش تجربه‌ها در صف مدیریت محتوا.
- Migration فاز ۴ (`Experience`، `ExperienceTag`، `ExperienceReference`، `ExperienceReuse` + توسعه `ContentReport`).

## فاز ۳ — اتاق مسئله (هسته محصول)

- مدل مسئله ساختاریافته: عنوان، شرح، زمینه/شرایط، نوع مانع، اقدامات انجام‌شده، نتیجه مورد انتظار، برچسب‌ها، فوریت، انتشار ناشناس، پیش‌نویس.
- وضعیت‌ها (open/discussing/solved/archived) با **تاریخچه وضعیت قابل پیگیری** (`ProblemStatusChange`).
- پاسخ ساختاریافته + «درخواست توضیح» + «مفید بود» (بدون لایک عمومی) + انتخاب راهکار با جمع‌بندی + ثبت نتیجه اجرا.
- هشدار/کنترل محتوای حساس پیش از انتشار (`content-safety.ts`)؛ محتوای مشکوک به صف بررسی ناظر می‌رود.
- گزارش محتوای نامناسب (`ContentReport`) + اقدامات نظارت (مخفی/حذف/بازیابی) توسط ناظر با Audit Log.
- تاریخ شمسی در UI (`dates.ts`) با ذخیره استاندارد UTC در دیتابیس؛ Rate Limit برای مسئله/پاسخ/گزارش.
- Migration های فاز ۳ (Problem، ProblemAnswer، Tag، ContentReport و...).
- صفحه‌های `/problems`، `/problems/new`، `/problems/[id]` و مدیریت محتوا `/admin/moderation`.

## فاز ۲ — هویت، احراز هویت و پروفایل حرفه‌ای

- ورود با شماره موبایل + OTP (Provider قابل جایگزینی؛ `devCode` فقط در توسعه)، Rate Limit، نشست امن (hash توکن + کوکی HttpOnly) و خروج از همه دستگاه‌ها (`logout-all`).
- Onboarding چهارمرحله‌ای و پروفایل حرفه‌ای: استان/شهرستان، سابقه بازه‌ای، مهارت‌ها/علایق، معرفی، Visibility.
- نقش‌ها (۸ نقش) + RBAC در Server و UI؛ درخواست و تأیید عضویت حرفه‌ای توسط مدیر.
- Audit Log برای ورود، ویرایش پروفایل و بررسی عضویت.
- Migration فاز ۲ (OtpCode، Session، MembershipRequest، Skill/Interest، AuditLog و توسعه User).
- رفع گیرنده: صفحه `/me` در `AppShell` قرار گرفت تا `ToastProvider` در دسترس باشد (خطای `useToast` رفع شد).

## فاز ۱ — بنیان فنی و سیستم طراحی (شروع)

- راه‌اندازی Next.js 16 (App Router, Turbopack) با TypeScript Strict.
- Design System: توکن‌ها، RTL، فونت Vazirmatn (self-host)، کامپوننت‌های پایه و App Shell.
- لایه دیتابیس: Prisma 7 + SQLite + adapter better-sqlite3؛ مدل پیش‌نویس User.
- ابزارهای پایه: zod (Validation)، logger، AppError، Vitest، ESLint، Prettier، CI اولیه.
- صفحات وضعیت: error / global-error / loading / not-found و پیش‌نمایش `/ui`.
