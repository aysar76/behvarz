# محدوده محصول (Product Scope)

**وضعیت:** نسخه اولیه برای فاز ۱ — تاریخ: مهر ۱۴۰۵

## جایگاه محصول

> **«هم‌بهورز» خانه حرفه‌ای بهورزان است.**

پلتفرمی مستقل، موبایل‌فرست و فارسی برای جامعه حرفه‌ای بهورزان و مراقبین سلامت. سیب محل کار رسمی است؛ این پلتفرم فضای غیررسمی، امن و انگیزشی برای «یادگیری، هم‌افزایی و حل مسئله» است.

## هسته MVP (فازهای ۳ تا ۸)

1. **اتاق مسئله** — ثبت مسائل واقعی با ساختار مشخص، پاسخ ساختاریافته، انتخاب راهکار و ثبت جمع‌بندی/نتیجه.
2. **بانک تجربه‌های میدانی** — تبدیل تجربه‌های پراکنده به دانش قابل جست‌وجو با وضعیت‌های `user_generated → reviewed → featured`.
3. **تعاملات حرفه‌ای و سرمایه روایت** — دنبال‌کردن موضوع/تجربه، «تشکر حرفه‌ای»، پروفایل اعتبار شواهد‌محور.
4. **حلقه‌های همیار** — گروه‌های کوچک ۵ تا ۱۲ نفره برای همکاری هدفمند.
5. **حکمرانی محتوا و ایمنی** — صف گزارش، مخفی‌سازی، تعلیق، تاریخچه تصمیم ناظر.
6. **جست‌وجو، اعلان و کشف دانش** — دسترسی سریع به دانش و افراد مرتبط.

## قلمروهای خارج از محدوده (ممنوع)

- کار روزانه رسمی: «امروز من»، «خانواده من»، پرونده، ارجاع (متعلق به سیب).
- هرگونه ذخیره‌سازی اطلاعات هویتی/پزشکی بیمار.
- پیام‌رسان عمومی / شبکه اجتماعی سرگرمی / چت آزاد.
- لیدربورد سراسری و لایک عمومی.
- فروشگاه، کیف پول و سیستم مالی پیچیده.

## اصل طلایی هر قابلیت

> هر قابلیت باید **بار را کم کند، نیاز را زیاد کند یا اثر را قابل مشاهده کند.** قابلیتی که هیچ‌کدام را انجام ندهد، ساخته نمی‌شود.
