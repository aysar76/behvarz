# محدودیت‌های شناخته‌شده (Known Limitations)

**وضعیت:** به‌روزرسانی با وضعیت واقعی کد — تاریخ: مهر ۱۴۰۵

## محدودیت‌های عمدی

| مورد                          | توضیح                                                                     | زمان بازبینی               |
| ----------------------------- | ------------------------------------------------------------------------- | -------------------------- |
| SQLite در توسعه               | مقیاس/قابلیت‌های Production ندارد؛ مسیر مهاجرت به PostgreSQL در فاز ۱۳    | فاز ۱۳                     |
| ارسال OTP واقعی (SMS)         | Provider فقط `dev` است؛ کد در پاسخ API در حالت غیر Production دیده می‌شود | فازهای بعد با زیرساخت قطعی |
| مسیرهای ناوبری                | آیتم‌های ناوبری «به‌زودی» غیرفعال‌اند تا فاز ۳+                           | فاز ۳                      |
| Toast/Modal بدون آزمایش حرکتی | MVP هیچ انیمیشن ورود/خروج ندارد (سبک و کم‌مصرف)                           | هنگام نیاز                 |
| فهرست استان‌ها/مهارت‌ها ثابت  | در کد تعریف شده‌اند؛ مدیریت پویا توسط مدیر در فاز ۷                       | فاز ۷                      |
| گزارش‌دهی Audit بدون UI       | لاگ‌ها ثبت می‌شوند؛ داشبورد ممیزی در فاز ۷/۱۰                             | فاز ۷                      |
| تست Integration برای API      | تست‌های واحد لایه‌های منطقی موجود؛ تست Integration در فاز ۱۳              | فاز ۱۳                     |

## نکات فنی

- `next/font/local` به نسخه فایل فونت محلی وابسته است (`src/fonts/vazirmatn-variable.woff2`).
- خروجی Prisma Client (`src/generated/`) تولیدشده است و نباید ویرایش شود.
- CI (GitHub Actions) فرض می‌کند `prisma migrate` و `prisma generate` قابل اجرا هستند (نیازمند `.env` با `DATABASE_URL`).
- درخواست‌های OTP در حالت توسعه Rate Limit دارند (IP: ۱۰/۱۰دقیقه، شماره: ۳/۱۰دقیقه).
